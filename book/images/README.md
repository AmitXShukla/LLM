# images

Figures and diagrams used in the chapters.

Name files after the chapter that uses them:

```
step-01-attention-shapes.png
step-03-fertility-comparison.png
step-09-loss-curve.png
```

Prefer SVG for diagrams and PNG for screenshots. Keep files small.

Always give figures alt text in the chapter, so screen readers and the PDF
build work correctly:

```markdown
![A chart comparing tokens per word across four tokenizers.](images/step-03-fertility-comparison.png)
```
